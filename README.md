## 本地运行

项目使用 [uv](https://docs.astral.sh/uv/) 管理依赖（Python 3.13）：

```bash
uv sync                              # 安装依赖
ENABLE_DEBUG_PRINT=true uv run python main.py   # 抓取全部站点并更新 README
uv run python website_github.py      # 单独运行某个站点
```
